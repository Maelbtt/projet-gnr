Notre méthode

Trois étapes, chaque vendredi.

  1. Tri chiffré. Chaque valeur est notée contre son sous-secteur sur la valorisation, les révisions de bénéfices, les surprises et la dynamique de cours.
  2. Avis sectoriels. Nos convictions, détaillées dans les fiches Secteurs, ajustent ces notes valeur par valeur.
  3. Optimisation sous contraintes. Le portefeuille maximise le rendement attendu pour un écart de suivi de 3,5 %, avec ±3 pts par titre et les ratios 5/10/40. Les écarts par secteur sont fixés par nos avis sectoriels ; les scores choisissent les sociétés dans chaque secteur.
